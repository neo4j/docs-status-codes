= 42I42

== Status description
error: syntax error or access rule violation - invalid use of `YIELD`. Cannot use `YIELD` on a call to a void procedure.

== Explanation
Void procedures do not return a result, so no result column can be yielded from them.
The `YIELD` clause is not applicable on a call to a void procedure.

== Example scenarios

Let's take the following example scenarios:

=== Yielding a result column from a void procedure
Try to yield result columns from the call of a procedure that does not return a result:

[source,cypher]
----
CALL db.createLabel("A") YIELD label
RETURN label
----

The query returns a chain of errors where GQLSTATUS 42I42 is the cause of GQLSTATUS xref:errors/gql-errors/42001.adoc[42001]:

.GQLSTATUS error chain
[source, error]
----
42I42: syntax error or access rule violation - invalid number of procedure or function arguments. Cannot use YIELD on a call to a void procedure.
  42001: syntax error or access rule violation - invalid syntax
----

In this case, call the procedure without a `YIELD` clause.
