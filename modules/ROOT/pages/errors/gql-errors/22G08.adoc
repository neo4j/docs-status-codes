= 22G08


== Status description
error: data exception - invalid duration function field value

== Scenario

A temporal field, such as `years`, `days`, `hours`, `minutes`, in the map provided argument of one of the temporal functions `duration()` has an invalid value.

== Possible solution

Adjust the value.
